# カギメモ — iPhone用 パスワードメモ（PWA）

ID・パスワードを **iPhoneの中だけで暗号化して保存** し、Face ID（パスキー）で解除するアプリです。
サーバーへの送信は一切ありません。

## できること
- 一覧の **[ID] [PW] ボタンを1タップでコピー**（開かずにコピペできる）
- 詳細画面から ID / パスワード / URL を個別にコピー、パスワードの表示切替
- 強いパスワードの自動生成（16〜32文字・記号あり/なし）
- 検索（名前・ID・URL・メモ）
- 自動ロック（操作なし1〜10分／他アプリへ切替後すぐ〜3分）
- アプリ切替画面（マルチタスク画面）で中身を隠す
- コピーした内容を一定時間後に消去
- 暗号化バックアップの書き出し・復元、パスフレーズ変更、Face ID再登録

## 公開手順（GitHub Pages・無料）
パスキーは「https の決まったアドレス」でしか動かないため、一度ネットに置く必要があります。
置くのはアプリの“入れ物”だけで、パスワードのデータはiPhoneの外に出ません。

1. https://github.com でアカウントを作成（パソコンのブラウザでOK）
2. 右上の「＋」→「New repository」→ 名前を `kagimemo`、**Public** を選んで作成
3. 「uploading an existing file」をクリックし、このフォルダの中身を全部ドラッグ＆ドロップ
   （`index.html` `app.js` `style.css` `sw.js` `manifest.webmanifest` `icons` フォルダ）→「Commit changes」
4. リポジトリの「Settings」→ 左の「Pages」→ Branch を `main` / `(root)` にして「Save」
5. 1〜2分後、`https://（ユーザー名）.github.io/kagimemo/` で開けるようになります

## iPhoneでの使い始め
1. iPhoneの **Safari** で上のアドレスを開く
2. 共有ボタン →「ホーム画面に追加」（※必ずホーム画面から使う。Safariのままだとデータが消えることがあります）
3. ホーム画面の「カギメモ」を開く →「はじめる」
4. 復旧用パスフレーズ（10文字以上）を決める → **紙に書いて保管**
5. 「Face ID（パスキー）を登録」→ 保存先は「パスワード（iCloudキーチェーン）」を選ぶ
6. 登録後、念のため「設定 → 暗号化バックアップを書き出す」で「ファイル」アプリかiCloud Driveに保存

## 大事な注意
- **パスフレーズを忘れ、Face IDも使えなくなると、誰にも復旧できません。**
- バックアップはこまめに（設定画面から1タップ）。機種変更時はバックアップから復元します。
- 公開アドレスを変えると、Face IDの登録が使えなくなります（パスフレーズで解除 → 設定で再登録すればOK）。
- 同じGitHubアカウントのPages（`ユーザー名.github.io`）に他のアプリを置かないでください。同じアドレス扱いになり、分離が弱くなります。
- GitHubアカウントには2段階認証を設定してください（アプリ本体を書き換えられないように）。
- iPhoneの「ユニバーサルクリップボード」が有効だと、コピーした内容が近くのMacにも届きます。気になる場合は「設定 → 一般 → AirPlayと連係 → Handoff」をオフに。
- iOSの制約で、コピーの自動消去は「時間経過後にアプリへ戻って画面をタップしたとき」に実行される場合があります。

## 仕組み（技術メモ）
- データ: AES-GCM 256bit で暗号化して IndexedDB に保存
- 鍵: ランダムなデータ鍵を、次の2つで包んで保存
  - パスキーの PRF 拡張出力 → HKDF-SHA256（iOS 18以降・iCloudキーチェーンのパスキーで対応）
  - パスフレーズ → PBKDF2-SHA256 600,000回
- 解除後の鍵はメモリ上のみ（取り出し不可の CryptoKey）。ロックで破棄
- 外部スクリプト・通信なし（Content-Security-Policyで禁止）
- 更新時は `sw.js` の `CACHE` のバージョンを上げてアップロード
